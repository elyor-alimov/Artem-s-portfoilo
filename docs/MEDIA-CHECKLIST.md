## Что является placeholder

Блок Campaign film — оформленный слот для будущего видео с реальным проектным постером и явной подписью ORIGINAL FOOTAGE TO FOLLOW. Он не выдаётся за видеоролик и не содержит неработающую кнопку Play. Если реальный файл изображения недоступен, `Media` показывает типографическую композицию с подписью VISUAL ARCHIVE / COMING INTO FOCUS. Случайные stock-фото и сгенерированные псевдокампании не используются.

## Проверка после замены

- [ ] Изображения соответствуют проекту и подписи.
- [ ] Права и разрешения на публикацию подтверждены владельцем материалов.
- [ ] На mobile нет непреднамеренного кадрирования важных элементов.
- [ ] Видно мелкий текст там, где он необходим для понимания.
- [ ] Фото оптимизированы, цвет и пропорции корректны.
- [ ] Видео запускается вручную, звук не включается автоматически.
- [ ] `npm run build` проходит; маршруты и CV открываются.
